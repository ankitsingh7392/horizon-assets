# horizon-assets

Public store artwork (logos, banners) for Horizon tenants. One folder per store slug.

Use the **raw** URL in the Branding tab, e.g.
`https://raw.githubusercontent.com/ankitsingh7392/horizon-assets/main/star-cafe/banner.jpg`

Keep files under 1 MB. JPG for photos/banners, PNG for logos with transparency.
